## GitHub Pages — za darmo
1. Załóż publiczne repozytorium, np. `portfolio`.
2. Wgraj wszystkie pliki z paczki do głównego katalogu repozytorium.
3. Wejdź w **Settings → Pages**.
4. W **Build and deployment** wybierz **Deploy from a branch**.
5. Wybierz `main` oraz `/ (root)`.
6. Otrzymasz adres podobny do `https://login.github.io/portfolio/`.

## Cloudflare Pages — za darmo
1. Utwórz projekt Pages.
2. Połącz repozytorium GitHub.
3. Nie ustawiaj frameworka ani komendy build.
4. Wdróż katalog główny.

## Bezpieczeństwo
Nie publikuj adresów IP, nazw hostów, screenshotów paneli administracyjnych pracodawcy, schematów sieci, danych klientów, haseł/tokenów ani szczegółowych konfiguracji bezpieczeństwa. Case studies w tej wersji są celowo opisane na bezpiecznym poziomie ogólności.
